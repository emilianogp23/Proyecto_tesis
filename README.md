# Proyecto_tesis
Implementar un optimizador de trayectorias para un vehı́culo aéreo no tripulado,  equipado con cámara monocular, con el fin de maximizar la cantidad de información para la reconstrucción 3D de un objeto de interés, garantizando al mismo tiempo un consumo energético eficiente del vuelo, comparando su desempeño con trayectorias estándar.
